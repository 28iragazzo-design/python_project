A project I worked on during shop class, where you can play the card game UNO right through the terminal of Python.

Tutorials I used from YouTube (They were created by Scott Blenkhorne): 

https://www.youtube.com/watch?v=7BXDcBfk-04
https://www.youtube.com/watch?v=-Y2YIEhU75M 
https://www.youtube.com/watch?v=cVX7hR3bX7A 

It can go as low as two players and up to four players.

Four different colors were established, cannot input a different color card in the pile.

Special cards were added, the most buggy thing but kind of work.

A win message should pop up if a player were to win by having zero cards.
